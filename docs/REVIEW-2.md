# 第二轮代码审查与改进

本轮以 `b984078e8d2cd0fbd84dfdcc09137b53eeed62c4` 为基线，收尾本地已有改动，系统检查 Cloudflare、ACME、持久化、初始化、配置重载、资源所有权及发行来源。交付仅包含代码、文档与隔离验证；运行中的生产服务保持原部署。

## 问题与修复

| 风险 | 改进 | 行为验证 |
|---|---|---|
| 列表分页可能过早完成，查询预算只计算 result | 完整分页、ID/名称/统计核对；单响应 1 MiB、累计完整响应 16 MiB | 超过 100 页、缺失元数据、提前空页、重复/变动记录、正文外填充预算 |
| 凭据读取失败被上层误报为远端写入不确定 | `NotSentError`、明确 API 拒绝、不确定结果分开；不确定退出码 5 优先于取消 130 | 无 HTTP 请求时不保留本次 pending；丢失响应保留日志、只读核对恢复 |
| 读取失败或超限丢失 Retry-After，底层错误可能暴露正文 | 所有响应失败保留状态与等待窗口，使用安全错误原因 | 503/429、截断、超限、协议异常与敏感内容保护 |
| TXT 清理依赖整列表，普通 404 易被误当作不存在 | 已知 ID 精确查询；明确记录不存在证明才清除日志 | HTML 404、其他错误码、错 ID、外部修改均保留日志且不删除 |
| 证书完整发布后目录同步失败导致丢弃有效快照 | 保留可用 TLS 快照，重试本地目录同步 | 注入发布后失败，握手可用且维护不访问 CA |
| HTTP 连接池所有权依赖可变全局默认 Transport | 显式创建自有连接池；借入客户端保持调用者所有权；缓存读取与网络客户端分离 | 自定义默认 Transport、借入连接池、关闭与在途取消 |
| 预览存在误执行或恢复安装的风险 | 独立预览端点；prepared/ready 初始化预览不恢复 | 旧服务拒绝预览、预览不更新 TLS/额度、不创建部署目录 |
| 重载未核对命令所选配置，service reload 绕过标准路径约束 | 请求携带绑定配置路径；标准服务与前台实例入口一致 | 错配置与状态目录组合、无效预览响应、结构变更、并发及关闭 |
| 重复 init 静默忽略凭据和导入来源 | 显式来源按内容断言，一致无操作，差异拒绝 | Token、身份、证书差异保护及等价手动证书路径 |
| 本地打包可能包含未跟踪文档或受外部 Go 参数影响 | 干净 HEAD 快照、只提取普通受跟踪文件、禁用 GOWORK/GOFLAGS | 脏源码、错 SHA、忽略凭据、链接、外部 overlay 与可重复构建 |

恢复沿用未知 A/AAAA 创建结果两分钟、未知 TXT 创建结果一分钟的等待窗口。恢复日志和所有权标记保持独立；不会覆盖外部修改或擅自重建被删除的受管地址记录。API 查询与写入之间无法提供跨管理方事务，应维持单一 DNS 管理方。

Go 实现继续使用调用方所需的小接口、具体业务类型、显式 context、不可变快照及创建者负责的任务生命周期。DERP 数据帧、STUN、MetaCert 和 Mesh 协议复用上游实现；本轮不增加监控接口或用户配置字段。

## 验证与性能

本地全量 Go 测试、race、Python 测试与分析检查用于缺陷回归。控制面基准采用同一 fixture，2/1,000 条记录，每页 100 条，包含统计元数据；不包含真实网络及 fixture 构造。基线与候选版本交替执行五次，计时与 profiling 分开。

本地预验收中，1,000 条记录的 B/op 从 1,455,012 降至 1,348,692，约减少 7.3%；耗时中位数从 2.953 ms 变为 3.026 ms，约增加 2.5%；allocs/op 从 1,695 变为 1,718。2 条记录为 15.801/16.146 µs、5,821/5,982 B/op、52/56 allocs/op。连接配额仍为 0 B/op、0 allocs/op。这些数据反映新增校验成本与容量优化，不代表公网或转发吞吐提升。

完整验收使用隔离 GitHub Actions：三组成对试验、1,000 个客户端、每版本每轮 600 秒。门槛为吞吐比中位数至少 0.95、P99 比值中位数至多 1.10；故障、内存预算、profiling 与资源回收必须全部完成。工作流另外保存五组成对控制面原始基准。

完整工作流结果与最终受测提交将在验收完成后补录；当前本地测试不能代替该验收。CI 同时覆盖双架构原生包、真实隔离 systemd 安装/重载、权限、身份保留与重建一致性。
